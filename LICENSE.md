# Licence

No licence has been chosen for victory-world's own files yet. Until the maintainer adds one, nothing here grants
a licence to reuse them.

The runtime (VIctory) is a separate project under GPL-3.0-or-later, in its own repository. victory-world holds the
coordination files that go with it: the agent instructions, the known-faults page, the issue board and the harness.

What these files would need:

- The harness is code. If it links with the runtime or is built from it, it needs a licence compatible with
  GPL-3.0-or-later.
- The instructions, the known-faults page and the issue board are documentation. They could take the same licence,
  or a Creative Commons one.

The choice is the maintainer's, and it is recorded here when made.
